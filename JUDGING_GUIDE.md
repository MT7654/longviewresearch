## One-paragraph description

Longview Research is a global equity-learning agent that helps retail investors understand the assumptions behind stock valuation. It resolves the exact listing, discloses data coverage, calculates reverse DCF, scenario DCF, relative valuation, seeded Monte Carlo uncertainty and transparent factor proxies, then uses an optional Gemini tutor to challenge fragile assumptions. Canonical numbers are calculated in deterministic TypeScript, not generated by the model. It provides educational ranges and learning checks rather than personalised advice or buy/sell/hold outputs.

## Why this is a Life Agent

The product develops an individual’s financial capability. Its outcome is not a report sold to a business; it is a learner who can:

- explain why target prices differ;
- identify the inputs behind a valuation;
- test sensitivity to growth and discount rates;
- interpret uncertainty as a range;
- recognise missing data; and
- challenge a model before relying on it.

## What makes the AI usage substantive

The agent is a workflow, not a chat panel:

1. Resolve a security.
2. Validate coverage.
3. Run deterministic models.
4. Ask Gemini to challenge assumptions.
5. Fall back locally when rate-limited.
6. Teach and test comprehension.

The language model is deliberately prevented from owning canonical arithmetic. This reduces hallucination while preserving the capabilities where a model adds value: structured critique and explanation.

## Demo script — approximately 3 minutes

### 0:00–0:25 — Problem

Show the landing page.

Say:

> Retail investors see target prices presented as answers. Longview reframes a target as the output of assumptions and teaches the user how to inspect them.

### 0:25–0:45 — Global resolution

Open NVDA and point to:

- symbol;
- exchange;
- country;
- currency;
- sample/live badge; and
- coverage panel.

Explain that other exact provider symbols can be searched globally, while missing fundamentals create a partial-data state.

### 0:45–1:15 — Reverse DCF

Show the implied-growth result.

Say:

> Longview works backwards from the reference price. It does not claim this growth will happen; it reveals what the other assumptions require.

### 1:15–1:55 — Valuation Lab

Move growth and discount-rate controls.

Show:

- scenario DCF;
- relative value;
- Monte Carlo median and range;
- distribution; and
- sensitivity matrix.

Emphasise that all calculations update without an AI call.

### 1:55–2:20 — Factor lens

Show value, quality, momentum and low-volatility proxies, plus historical drawdown.

State that these are descriptive systematic-investing concepts, not candlestick analysis or trading signals.

### 2:20–2:40 — Model challenger

Select **Challenge this model**.

If Gemini is available, show the model label. If it is rate-limited, show the deterministic fallback and explain that the entire calculation desk remains functional.

### 2:40–3:00 — Learning and boundaries

Answer the learning check and show the source ledger.

Close with:

> Longview never asks about the user’s holdings, income, risk tolerance or position size. It teaches assumptions and uncertainty without deciding suitability.

## Judging dimensions

### AI Innovation — 30%

- Agentic resolve–validate–model–challenge–teach sequence.
- AI is placed where judgement and explanation help.
- Calculations remain reproducible outside the model.
- Graceful Gemini free-tier degradation.

### Technical Excellence — 20%

- Strict contracts for security, fundamentals, coverage and sources.
- Stable-model routing with bounded retry, cooldown and cache.
- Numerical reverse solving and deterministic simulation.
- Explicit unsupported-instrument and missing-data states.
- Formula-level tests.

### User Experience — 25%

- Product begins with the user’s real question: a stock search.
- Institutional visual language without Bloomberg-level complexity.
- Assumptions and outputs share one workspace.
- Responsive design and printable report.
- Integrated comprehension check.

### Business Value — 25%

- Addresses a widespread financial-literacy gap.
- Works without brokerage integration.
- Global symbol architecture supports future market-data licensing.
- Conservative non-personal design reduces avoidable regulatory risk.

### Product sharing

> I used Tencent Cloud CodeBuddy to convert an earlier market-research application into the foundation of a consumer investment-learning agent. CodeBuddy helped map the initial product pivot and accelerate changes across a large Next.js codebase. That process also exposed an important lesson: agent-generated code still needs explicit mathematical tests, data-provenance rules and product-scope review. The final Longview architecture separates Gemini’s explanatory role from deterministic valuation code, making every calculated output reproducible and allowing the demo to keep working when free-tier inference is rate-limited.

### Defined impact

- Every displayed valuation output traces to visible inputs.
- No personal suitability profile is collected.
- No buy/sell/hold output is generated.
- The full sample flow runs without credentials.

## Honest limitations

- live global fundamentals;
- licensed real-time prices;
- a Fama–French regression;
- production regulatory approval;
- personalised suitability;
- a predictive target price; or
- guaranteed Gemini availability.

The product demonstrates global identity and price-history handling, deterministic educational models, carefully labelled frozen fundamentals and a credible path to licensed production data.
